문제 개요

Hamiltonian

H = Σj=0N-1 ( Jx·XjXj+1 + Jy·YjYj+1 + Jz·ZjZj+1 ) + hx · Σj=0N-1 Xj

경계 조건은 주기적(periodic): 인덱스 j+1은 mod N으로 계산. 초기 상태는 Néel 상태 |ψ₀⟩ = |010101⟩ (qubit-0-first 표기). 시간 격자: t = 0, 0.05, …, 15.0 (총 301점).

Problem 1(a)

Hamiltonian 구성

완료

풀이 방법

Qiskit SparsePauliOp.from_list()를 사용해 구성. Qiskit의 Pauli 문자열 컨벤션: 가장 오른쪽 문자가 qubit 0. qubit j에 연산자 P를 배치하려면 chars[N−1−j] = P.

def _site_pauli(paulis, sites, n):
    chars = ['I'] * n
    for p, s in zip(paulis, sites):
        chars[n - 1 - s] = p
    return ''.join(chars)

# 예: Z on qubit 1 (N=6) → "IIIIZI"
# 예: ZZ on qubits 0,1    → "IIIIZZ"

Problem 1(g)

정확도 vs. 회로 깊이 토론

완료

Q1. 같은 반복 수 k에서 가장 정확한 공식은?

ST4 > ST2 > LT. LT는 1차(오차 O(Δt²)), ST2는 2차(O(Δt³)), ST4는 4차(O(Δt⁵)). k=1, t=0.5 기준으로 infidelity가 LT≈0.28 / ST2≈0.015 / ST4≈3×10⁻⁵로 급격히 줄어든다.

Q3. 깊이–정확도 트레이드오프

ε ∝ Δtp+1 = (t/k)p+1 (p: 공식 차수) depth ∝ k (선형 증가)

k를 늘리면 Trotter 오차는 기하급수적으로 줄지만 회로 깊이·2Q 게이트 수는 선형 증가한다. 하드웨어 노이즈 환경에서는 과도한 k가 오히려 총 오차를 키울 수 있으므로, ZNE 같은 에러 완화와 조합이 필요하다.

A(t) = ⟨ψ₀|e−iHt|ψ₀⟩ = Σn |⟨En|ψ₀⟩|² e−iEnt

결과

  • Re[A(t)]: 빠른 진동 (최대 주파수 ≈ 고유에너지 범위)

Problem 2(b-c)

Hadamard-test 회로를 통한 Trotter 자기상관

완료

풀이 방법: Hadamard-test 회로

APF(t) = ⟨ψ₀|UPF(t)|ψ₀⟩ 를 측정하는 N+1 큐비트 회로:

큐비트역할회로 (Re 파트)
q[0]보조(ancilla)H → 제어 → H → 측정
q[1..N]시스템|ψ₀⟩ 준비 → UPF(t) 적용
def hadamard_test_circuit(t, synthesis, part='real'):
    qc = QuantumCircuit(N + 1)
    qc.h(0)                                      # ancilla → |+⟩
    for i, bit in enumerate(reversed(BITSTRING_NEEL)):
        if bit == '1': qc.x(i + 1)              # system → |ψ₀⟩
    ctrl_gate = PauliEvolutionGate(H_spo, time=t,
                    synthesis=synthesis).control(1)
    qc.append(ctrl_gate, range(N + 1))           # controlled-U_PF
    if part == 'imag': qc.sdg(0)                # S† for Im part
    qc.h(0)
    return qc

# P(|0⟩) - P(|1⟩) on ancilla = Re(A_PF) or Im(A_PF)

Problem 2(d-e)

Fourier 스펙트럼 분석

완료

풀이 방법

A(t) = Σn |⟨En|ψ₀⟩|² · e−iEnt ⟹ DFT[A](ω) 의 피크 위치 = 초기 상태와 겹침이 있는 고유에너지 En 
window      = np.hanning(len(TIMES))
spectrum    = fftshift(fft(A_exact * window))
freq        = fftshift(fftfreq(len(TIMES), d=DT_GRID))
energy_axis = -2 * np.pi * freq    # A(t) = Σ exp(-iE_n t) → peak at E_n

결과 및 설명

왜 특정 고유에너지에서만 피크가 나타나는가?
A(t) = Σn cn·e−iEnt 에서 cn = |⟨En|ψ₀⟩|². 초기 상태 |ψ₀⟩와 겹침이 0인 고유상태(cn=0)는 A(t)에 전혀 기여하지 않으며, DFT 스펙트럼에 피크를 만들지 않는다.

N=6 Néel 상태의 경우, 총 64개 고유상태 중 에너지 보존·대칭에 의해 겹침이 유의미한 고유상태 수가 제한된다. DFT 스펙트럼의 피크 수 = 겹침 임계값(1%·최대값)을 초과하는 고유상태 수.
